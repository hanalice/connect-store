# PM 裁决（施工与 QA 验收均以本节为准）

## 裁决①：加购入口形态——wrapper 兄弟节点，不改进 ProductCard 本体

- **ProductCard 点击行为已核实**：纯展示 + `role="button"` + aria-label，**无 onClick /
  无导航**——不存在真实点击导航冲突；冲突面只在 a11y（交互元素嵌套）与 E2E 查询。
- 方案拍板：grid 单元内 = **wrapper div 包 `<ProductCard>` + 加购按钮兄弟节点**
  （按钮不得作为 ProductCard 的 DOM 后代，防嵌套交互语义；不得遮挡卡片图片 / 价格；
  具体视觉形态 coder 定）。按钮 accessible name = `加入购物车，{title}`——E2E 与单测
  按 name 定位，不依赖视觉选择器。
- `ProductCard` / `ProductGrid` / `EmptyState` 本体与 scss **零改动**（越界即返工）。

## 裁决②：目录页挂载 = AssistantPage 先例

CatalogPage 页头挂 `<CartBadge />`（条目数角标，全局共享 store）、页面根部挂
`<CartDrawer />`——store 全局单例，persist 跨页自然生效（同一 localStorage 源），
**本 G 零 store 逻辑**。

## 裁决③：E2E 拍板——加 E2E-AI-18，catalog 数据走 page.route 回放

- catalog 页数据来自**远程绝对 URL**（`productApi.ts`
  `https://closet-recruiting-api.azurewebsites.net/api/data`），不经 vite proxy、
  mock-bff 不服务该路径——E2E 必须 `page.route` 对该 URL 确定性回放 2 件商品快照
  （A2 浏览器版模式），**不改 productApi、不动 mock-bff**。
- E2E-AI-18：目录页加购（点「加入购物车，{title}」）→ CartBadge 计数 +1 → 开抽屉见
  条目 → `page.reload()` 后角标与抽屉内容恢复（persist 跨页实证）。mock 门禁
  16 → 17 条，三连跑无 flake。
