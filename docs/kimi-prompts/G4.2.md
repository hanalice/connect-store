# PM 裁决（施工与 QA 验收均以本节为准）

## 裁决①：5 分钟口径双轨校验（主判计时 + 辅判预算）

- **主判：计时演练**——按 README 内嵌「讲述大纲」口头演练一遍并计时，**≤300s**，
  六必备章节全覆盖；演练用大纲（章节 → 每章 2~4 个讲述要点）以 HTML 注释块嵌在
  README 内（渲染不可见、源文件可见，讲述者视角）。
- **辅判：体量预算**——README 全文 **≤200 行** 且 `wc -m` ≤ 4000 字符当量
  （中英混合按字符计，实测贴数）；超预算 = 删减信号，不豁免。
- 两轨都要实测证据：计时秒数 + 行/字符数原始输出行贴报告。

## 裁决②：语言与诚实声明纪律

- **骨架英文 + 讲述大纲中文**（存量 README 惯例英文；演练母语中文；H3 审阅可再调）。
- **删除一切不诚实/过时声明**：存量「100% test coverage」必须删除，改为实测口径
  （引 regression-index §1）；不写 design 没有的能力（语义检索已撤销——D6 撤销理由
  可讲但不可用现在时陈述）。

## 裁决③：引用纪律（数字唯一事实源）

  完工出「README ↔ §1 对账表」（逐条列出 README 中的数字与 §1 出处行）。

4. **HITL 流程**（六步：对话→推荐→加购→下单→审批→订单号 + expired/伪造拦截一句，
