# 要做的事

1. **依赖**：在 `server/` 内追加 `hono`、`@hono/node-server`、`dotenv`；devDeps 追加 `typescript@^7.0.2`（**直接装 typescript 7.0.2，不要装 `@typescript/typescript6`** —— server 没有 eslint，不需要 TS6 兼容层）、`tsx`、`@types/node`。仍用 npm，**不声明 workspaces**。
2. **`server/tsconfig.json`**：新建。ESM（package.json 若缺 `"type": "module"` 则补上）、`strict: true`、`noEmit: true`（类型检查用，运行交给 tsx）、`skipLibCheck: true`、target/module 选 Node 22 适配组合。
3. **`server/env.ts`**：读取 `LLM_API_KEY` / `LLM_BASE_URL` / `LLM_MODEL` / `APPROVAL_SECRET` / `PORT`（默认 **8787**）。**G1.1 阶段不得因缺少 LLM key 而启动失败**（本任务不需要真实 key），改为导出 `llmConfigured: boolean`。
4. **`server/index.ts`**：Hono 入口 + `@hono/node-server` 监听 `PORT`；`hono/cors` 白名单 `http://localhost:5173`（Vite 默认端口）；`GET /health` 返回 JSON：`{ status: 'ok', service: 'connect-store-bff', uptimeMs: <进程运行毫秒数>, llmConfigured: <boolean> }`。`uptimeMs` = `process.uptime() * 1000` 并取整到毫秒。
5. **`server/.env.example`**：五个变量占位 + 注释（`PORT=8787`、`LLM_BASE_URL` 示例）。**不要创建真实 `server/.env`**；确认 `.env.example` 会被提交、`server/.env` 不会被提交。
6. **`vite.config.ts`**：加 `server.proxy`：`'/api' → http://localhost:8787`（`changeOrigin: true`）。**只加这一段，不动其他配置。**
7. **根 `package.json`**：加 convenience 脚本 `"dev:bff": "npm --prefix server run dev"`（不声明 workspaces）。
