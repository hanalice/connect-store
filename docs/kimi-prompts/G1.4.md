# 要做的事

1. **Playwright 基建**
   - devDependency `@playwright/test`；`playwright.config.ts`（`testDir: 'e2e'`，
     `webServer` 自动起 `vite dev`，baseURL `http://localhost:5173`）
   - 根 `package.json` 加 `test:e2e` script（**不动 TS 双版本方案**）
   - `.gitignore` / `.prettierignore` 补 `playwright-report` / `test-results`
   - 只装 chromium（`npx playwright install chromium`），安装方式写进报告
2. **E2E mock 流夹具**（`e2e/`）
   - 复用 shared-assets A2 思路：固定 UIMessageChunk 帧序列
     （`data: {JSON}\n\n` 帧 + `[DONE]` 哨兵；Content-Type: `text/event-stream`）
   - **逐块增量渲染断言需要可控的帧间隔**。优先 `page.route('**/api/chat')` 拦截回放；
     若 `route.fulfill` 不支持分块流式写出（body 一次性到底则无法断言中间态），
     改用 webServer 起一个本地 mock BFF（8787 端口，按请求内容选场景）下发受控 SSE。
     两选一，报告 §三写明选择依据与验证
3. **E2E 用例**（全走 mock 流，确定性；编号补登 `docs/test_cases.md`，前缀 E2E-AI-）
   - 页面加载：`#/assistant` 进入，输入框 / 发送按钮可见
   - 逐块流式渲染（INT-AI-01）：分帧推 text-delta，断言中间态文本逐步增长
     （非一次性整段）；容器带 `aria-live="polite"`（A11Y-04）
   - 停止（INT-AI-02）：流式中点「停止」→ 提示条出现、输入框恢复可用、
     已收到部分文本保留、无错误横幅
   - reasoning 折叠：默认收起显示「思考过程」，点击展开可见内容
   - 智能滚动：长输出中流式上滑 → scrollTop 不被抢；回到底部 → 恢复跟随
   - 错误态-网络断：`route.abort()` → 错误横幅「无法连接服务器」，不白屏
   - 错误态-502：route 返 502（= 停 BFF 时的 proxy 行为）→ 横幅含 `HTTP 502`
   - 错误态-error chunk：流中推 `{"type":"error","errorText":"..."}` → 横幅显示该文案
4. **live 冒烟**（1 条，不进 CI/默认门禁）：真打 BFF 发一条消息，断言增量文本出现；
   用独立 project 或 grep tag 隔离，默认 `test:e2e` 不跑它，报告里写明手动触发方式
5. `docs/test_cases.md`：补登 E2E-AI- 用例编号与简述
