# 要做的事（编号，可勾选）

## 裁决①（PM，施工前必须先书面裁定）

方向 D 下用户「清空购物车」的执行通道二选一：

- **①-a 只读收口**：不做 clearCart。清空只能由 AI 逐件处理或用户清浏览器数据——工单作者不推荐（story 说 AI 是唯一写者，写者无法清理自己产物，story 反而破洞）。
- **①-b 收口 + clearCart 回执工具（推荐）**：新增 server 工具 `clearCart`（回执语义，零入参，execute 返回 `{cleared: true}`；客户端收到回执后调 `useCartStore.clear()`——与 addToCart「server 回执 + 前端应用」同模式）+ prompt 条款（用户要求清空时直接调用，调用后告知已清空）。

裁定写入 commit message 与 QA 报告输入。
