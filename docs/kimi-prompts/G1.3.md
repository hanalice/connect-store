# 现状

- `src/app/router.tsx`：`createHashRouter`，目前只有 `/` → `CatalogPage`
- `src/app/providers.tsx`：只有 `RouterProvider`
- 状态库：Zustand（`useCatalogStore` / `usePreferenceStore`，`zustand@^5.0.8`）
- 样式：SCSS Modules + CSS Variables（**不引 Tailwind**）
- BFF 已就绪：`POST /api/chat`（官方 UI 消息流）+ Vite proxy `/api` → `localhost:8787`
- **27 个存量测试必须零回归**

# 要做的事

1. **`src/features/assistant/services/chatApi.ts`（自研传输层）**
   - `fetch('/api/chat', { method: 'POST', headers, body: JSON.stringify({ messages }), signal })`
   - 读 `response.body` 为流，按 SSE 帧解析（`data: {...}` + 空行分隔）
   - **不发明事件类型**：直接消费官方 `UIMessageChunk` 的 `type`（实测见过 `start` / `start-step` /
     `reasoning-start` / `reasoning-delta` / `text-start` / `text-delta` / `text-end` / `finish` / `error`）
   - **先查 `node_modules/ai` 的类型/导出**：若存在可复用的流解析助手（如 `readUIMessageStream`、
     `parseJsonEventStream`），优先用官方实现；否则手写 SSE 解析，并为其写单测
   - 支持 `AbortSignal`；区分错误类型：网络失败 / 非 2xx（读 JSON body 的错误）/ 流中途断开
2. **`state/useAssistantStore.ts`（Zustand）**
   - state：`messages`、`status`、`error`
   - `status` 枚举**对齐 design §5，本任务只用子集**：`'idle' | 'thinking' | 'streaming' | 'error' | 'aborted'`
     （G2.2 会在此枚举上补 `tool_calling` / `tool_result` / `await_human` / `done` 并引入转换表，不要自造新名字）
   - actions：`sendMessage(text)` / `abort()` / `reset()`
3. **`components/StreamingText.tsx`**
   - 逐 chunk 渲染 `text-delta` 累积结果
   - **禁止 `setInterval` / `setTimeout` 人工打字机**（会掩盖 TTFT，且属假流式）
   - 容器加 `aria-live="polite"`
4. **`components/ReasoningBlock.tsx`**
   - 累积 `reasoning-delta` 内容，**默认折叠**（收起态显示"思考过程"），可展开
   - 无 reasoning 内容时不渲染
5. **`components/ChatPanel.tsx`**
   - 消息列表 + 输入框 + 发送按钮 + 停止按钮（`status === 'streaming'` 时可点）
   - 错误态展示（`status === 'error'` 时显示明确文案，不白屏）
   - **智能自动滚动**：仅当用户已在底部时跟随；用户上滑时不抢滚动
6. **`features/assistant/AssistantPage.tsx`** + 路由：`router.tsx` 新增 `/assistant`
7. **入口**：`CatalogPage` 加一个"AI 导购"链接（**最小改动**，不动现有筛选/搜索/滚动逻辑）
8. **样式**：`*.module.scss`，复用现有 CSS variables；不新增全局样式文件

- 不改 `eslint.config.js`、根 `package.json` 的 TS 双版本方案；不引 Tailwind
