## 五、风险与遗留

1. **HITL 绕过面（G3.2 预警）**：`placeOrder` 进工具注册表后，`TOOLS_DIRECT_ALLOW` 与注册表
   取交集的机制会**自动允许**把 placeOrder 写入白名单——`server/env.ts:15-16` 与
   `server/index.ts:37` 已有「永不入白名单」注释，但仅是注释级约束，G3.2 工单须把
   「placeOrder 不得可直调」列为验收项（建议加一条针对注册表的断言或启动期硬检查）。
2. **G2.3 扩展 tool 流时须同步 `e2e/mock-bff.mjs`**（G1.4 遗留）：mock 帧为手写
   UIMessageChunk，工具流格式漂移风险；本 G 未动流格式，e2e 8 条零回归已验证。
3. **Free / View Only 商品 price 非 0**（快照实测：Free min=10/max=10000，View Only
   min=1/max=450）：「20 刀以内」类查询会把高价的 Free/View Only 商品排除、把低价的 Paid
   商品纳入，G2.3 prompt 工程需明确价格区间过滤与 pricingOption 的语义关系，避免 LLM 误以为
   「免费 = price 0」。
4. **`server/.env` 的 `TOOLS_DIRECT_ALLOW` 为本地配置不随仓库**：QA / 演示环境需自配
   `TOOLS_DIRECT_ALLOW=searchCatalog,getProductDetails,addToCart`，否则直调端点全 404
   （这正是生产语义，但演示前漏配会造成「工具全挂」假象）。
5. 观察项（不阻塞）：根 / server vitest spec 均为 `^4.0.7` 但解析版本 4.1.0 / 4.1.12 漂移
   （见 §三③）；`.prettierignore` 文件末尾无换行符（存量风格，未改）。
