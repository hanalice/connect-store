### 6.3 H6 人工抽验建议抽查点（重试路径 + pending 保位的用户可感知行为）

1. **断网 → 重试**：对话中断网（DevTools offline）→ error 横幅出现「重试」按钮 → 恢复
   网络点重试 → **同一条原消息重发**（非新输入）→ 正常回复——重点感知「我说的那句话
   被记住了」；
2. **aborted 无重试**：流式中点「停止」→ 横幅**没有**重试按钮、只有降级链接 → 直接输入
   新消息正常发送——感知「取消后我像平常一样继续聊」；
3. **审批中断保位**（本 G 核心新行为）：下单进入审批卡后断网/杀 BFF → **无错误横幅、
   卡还在**（卡内「操作失败，可重试」）→ 恢复网络 → 点「确认下单」→ 订单号正常出现——
   感知「断网没把我的订单弄丢，也不用重来」；
4. **降级链接**：error / aborted 横幅点「或回目录手动选购 →」→ 跳转目录页且购物车
   角标与加购状态保留（G3.1a persist 跨页）；
5. **审批卡焦点圈禁**（A11Y-05）：审批卡出现时 Tab 键焦点在卡内三按钮间循环、不逃逸到
   composer（composer 已锁定），决策后焦点归还输入框。
