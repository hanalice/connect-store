## 三、缺陷清单

**Q-D-01（轻微·健壮性/文档）**：`E2E_MOCK_PORT` 未覆盖数据面第三腿——
`vite.config.ts` 的 `/api` 代理目标硬编码 `http://localhost:8787`，不随环境变量
迁移（diff 未触及该文件）。后果：字面 `E2E_MOCK_PORT=18787 npm run test:e2e`
（playwright 自拉 vite）数据面 502 全灭（§二.5 实测）；非标准端口跑法必须外置
代理重定向（harness 形态）。不影响标准端口/CI（5173→8787 恒成立），且 A5 补注
所述「两端同读」范围本身属实；但该心智模型易诱导后来者单变量换端口踩坑。
**建议**：`vite.config.ts` 代理 target 一行读 `E2E_MOCK_PORT`（属裁决②修复面的
自然补全），或在 A5 补注明示「数据面代理不在 E2E_MOCK_PORT 覆盖内」。

**Q-D-02（轻微·文档，前存遗漏）**：regression-index §2.1b 用例总索引漏
`server/env.test.ts`（7 用例）一行——该文件自 G3.2（commit 2eb39e4）引入即未登记
（HEAD 版本索引亦无此行，非 G4.1 引入）；G4.1 既已改动 §2.1b（增审批·TTL 域行）
仍未顺手补齐。§1 命令表总数 72 准确不受影响。**建议**：§2.1b 增补一行。
