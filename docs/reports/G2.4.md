## 四、通用资产沉淀

- zod 运行时校验白名单模式（裁决⑤落地形态）：`productSchema` 镜像存量 `Product` 契约 + `searchCatalogOutputSchema` / `getProductDetailsOutputSchema`，`safeParse` 失败 → 内联 `ToolError` 指示，不静默渲染坏数据；工具业务错误（输出体内 `error` 字段）先于 schema 校验分流。详见 `uiRegistry.tsx:30-59`。
- 渲染双层防护：`RegistryErrorBoundary`（捕获 React 渲染期抛错）+ `ToolOutputCard` 白名单查表（未注册 key 纯文本 fallback），G3.x 及后续 Generative UI 扩展可复用该骨架。
- E2E 计算样式列数断言法：`getComputedStyle(el).gridTemplateColumns.split(' ').length` `.toBe(2)`（`assistant.e2e.ts:244`），裁决⑥ wrapper 覆盖（`.toolGrid` 特异性高于视口媒体查询）的闭合证据。
- 气泡内渲染顺序固化：ReasoningBlock → ToolCallPanel（过程）→ uiRegistry 卡片（结果）→ StreamingText（`ChatPanel.tsx:94-115`），与裁决③一致。
