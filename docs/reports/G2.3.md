## 四、通用资产沉淀

- **mock-bff 双命名闸门模式**（`/__release?gate=pre/post` + 置位集 + 新对话清置位）：可复用于任何
  需要稳定断言「流中间态」的 E2E 场景，替代 sleep 竞猜。详见 `e2e/mock-bff.mjs` 头注释。
- **状态投影表模式**（`STATE_PROJECTION: Record<AssistantState, {label, tone}>`）：9 态单一静态映射
  表，新状态机态 UI 接入只加一行；await_human 先映射后接线的「占位先行」做法可供 G3.3 复用。
- **价格语义 system prompt 全文**（`server/chat-prompt.ts`）：pricingOption 枚举语义 +
  「免费 ≠ price 0」纠偏 + 区间意图与计价方式独立可组合，G3.x 加工具时须同步约束文案。
